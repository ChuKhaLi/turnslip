Know what Claude just did.

turnslip adds one line after every Claude Code turn: what changed on disk, what looks risky, and a one-command undo.

Install free See Pro

This line is turnslip. It lists what changed on disk, flags the risky parts, and names the undo.

What it catches

  • Shell changes

    Files a command created, changed or deleted count too, not only Claude's edits. npm install shows up as packages changed. What did Claude Code change?

  • Risky changes

    🔑 a key written to a file your .gitignore doesn't exclude, or a new .env, 🗑 deletions, 🗄 migrations, 📦 dependencies, 🚀 pushes and deploys, ⚠ writes outside the project.

  • What went unsaid

    When a file changed but Claude's reply did not mention it, the slip says not mentioned: config.js.

  • One-command undo

    /turnslip:undo puts the last turn's files back and keeps any file you changed since. How it compares with /rewind and git

Install

In a terminal:

claude plugin install turnslip@turnslip

Needs Claude Code 2.1.289 or later and Node.js 18 or later. Run /turnslip:setup in Claude Code to check.

How Pro is delivered

  1. Dodo Payments emails your receipt and your license key.
  2. In Claude Code, run /turnslip:activate <key>.
  3. One key works on up to 3 machines. Free one with /turnslip:deactivate.
  4. turnslip checks the key once a week and keeps working for 14 days offline.

Questions

Does anything leave my machine?

No. Snapshots and slips stay in ~/.turnslip. Pro sends only the license key and a machine id to Dodo Payments to check the license. Privacy

Can I get a refund?

Where is the source?

On GitHub, under FSL-1.1-MIT: read it, change it, use it; each version becomes MIT after two years.

How is this different from Claude Code's /rewind?

/rewind restores the edits Claude made with its file tools; it does not track files changed by shell commands. turnslip snapshots the project before and after each turn, so a file a command deleted or rewrote comes back too. They work side by side. How to undo Claude Code changes

Which tools does it work with?

Claude Code, in the terminal and in VS Code.
