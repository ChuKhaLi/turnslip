Know what Claude just did.

turnslip adds one line after every Claude Code turn: what changed on disk, what looks risky, and a one-command undo.

Install free See Pro

This line is turnslip. It lists what changed on disk, flags the risky parts, and names the undo.

What it catches

  • Shell changes

    Files a command created, changed or deleted count too, not only Claude's edits. npm install shows up as packages changed.

  • Risky changes

    🔑 a key written to a file your .gitignore doesn't exclude, or a new .env, 🗑 deletions, 🗄 migrations, 📦 dependencies, 🚀 pushes and deploys, ⚠ writes outside the project.

  • What went unsaid

    When a file changed but Claude's reply did not mention it, the slip says not mentioned: config.js.

  • One-command undo

    /turnslip:undo puts the last turn's files back and keeps any file you changed since.

Install

In a terminal:

claude plugin marketplace add ChuKhaLi/turnslip
claude plugin install turnslip@turnslip

Needs Claude Code 2.1.289 or later and Node.js 18 or later. Run /turnslip:setup in Claude Code to check.

How Pro is delivered

  1. Dodo Payments emails your receipt and your license key.
  2. In Claude Code, run /turnslip:activate <key>.
  3. One key works on up to 3 machines. Free one with /turnslip:deactivate.
  4. turnslip checks the key once a week and keeps working for 14 days offline.
